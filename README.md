# Task Tracker API 🚀

Backend-приложение для управления задачами (To-Do List) с JWT-авторизацией. 
Проект написан на Node.js, Express, TypeScript. В качестве базы данных используется SQL Server (через Prisma ORM).

## 🛠 Технологии
* **Node.js** (v22)
* **TypeScript** (v5)
* **Express.js** — веб-фреймворк
* **Prisma ORM** — работа с базой данных
* **SQL Server** — реляционная база данных
* **JWT (JSON Web Tokens)** — авторизация и защита маршрутов
* **Bcrypt** — хэширование паролей
* **Tsx** — запуск TypeScript в режиме разработки
