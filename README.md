# Task Tracker API 🚀

Полноценное backend-приложение (REST API) с визуальным интерфейсом для управления задачами (To-Do List). Реализована система аутентификации и авторизации пользователей с помощью JWT. Каждый пользователь имеет доступ только к своим задачам.

## 📖 О проекте и его функционале

Этот проект представляет собой готовый сервер, который умеет:
1. **Регистрировать пользователей** (с безопасным хэшированием паролей).
2. **Авторизовывать пользователей** (выдавать JWT-токены для доступа к закрытым данным).
3. **Создавать задачи** (с названием и описанием).
4. **Отображать список задач** конкретного пользователя.
5. **Изменять статус задачи** (например, с "В планах" на "Выполнено").
6. **Удалять задачи**.

Проект включает в себя простой веб-интерфейс (HTML/JS/CSS), который общается с сервером через Fetch API.

## 🧠 Как это работает (Архитектура и логика)

Проект построен по классической архитектуре **Client-Server**:

1. **Аутентификация:** 
   * При регистрации пароль пользователя не сохраняется в открытом виде. Он хэшируется с помощью библиотеки `bcrypt` (добавляется "соль" и 10 раундов шифрования).
   * При входе сервер проверяет пароль и выдает **JWT-токен** (JSON Web Token). Этот токен содержит ID пользователя и имеет срок действия.
2. **Защита маршрутов (Middleware):**
   * Для всех операций с задачами требуется заголовок `Authorization: Bearer <токен>`.
   * Специальный middleware (`auth.middleware.ts`) перехватывает запрос, проверяет валидность токена и извлекает `userId`. Если токена нет или он просрочен, сервер возвращает `401 Unauthorized`.
3. **Изоляция данных:**
   * При запросе задач сервер обращается к базе данных и ищет только те записи, где `userId` совпадает с тем, что был извлечен из токена. Это гарантирует, что пользователь А не сможет увидеть или удалить задачи пользователя Б.
4. **Работа с базой данных:**
   * Взаимодействие с SQL Server происходит через ORM **Prisma**. Схема базы данных описана в файле `schema.prisma`.

## 🛠 Технологии
* **Node.js** (v22) — среда выполнения
* **TypeScript** (v5) — типизированный JavaScript для надежности кода
* **Express.js** — веб-фреймворк для создания API
* **Prisma ORM** — удобная работа с базой данных
* **SQL Server** — реляционная база данных
* **JWT (JSON Web Tokens)** — авторизация
* **Bcrypt** — хэширование паролей
* **HTML/CSS/JS** — простой фронтенд (без фреймворков)
